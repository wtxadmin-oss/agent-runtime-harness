# nanobot 项目分析与启动指南

## 项目概览

**nanobot** 是一个开源的超轻量级 AI Agent 框架，灵感来自 Claude Code 和 Codex。核心设计理念是保持 Agent 循环小巧可读，同时支持聊天频道、记忆、MCP 和实际部署路径。

### 项目结构

```
nanobot/
├── nanobot/          # 后端 Python 核心代码（AI Agent 框架）
├── webui/            # 前端（React 18 + Vite + TypeScript + Tailwind）
├── bridge/           # WhatsApp bridge（Node.js）
├── docs/             # 项目文档
├── tests/            # 测试用例
├── pyproject.toml    # Python 依赖配置（版本 0.1.5.post2）
├── docker-compose.yml
├── Dockerfile        # 生产镜像
└── .devcontainer/    # Dev Container 开发环境配置
```

---

## 环境要求

| 组件 | 要求 |
|------|------|
| **Python** | `>= 3.11`（推荐 3.12） |
| **包管理** | `pip` 或 `uv`（推荐） |

## 方式一：Dev Container（推荐，隔离环境）

> 不污染本机环境，所有依赖都在容器内。

### 前提条件

- 安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- VS Code 安装 [Dev Containers 插件](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

### 启动步骤

1. 用 VS Code 打开项目根目录
2. `Cmd+Shift+P` → `Dev Containers: Reopen in Container`
3. 等待镜像构建完成（首次约 3~5 分钟）
4. 容器会自动执行 `pip install -e . && cd webui && bun install`

### Dev Container 配置说明

`.devcontainer/` 目录包含：

| 文件 | 说明 |
|------|------|
| `devcontainer.json` | 端口转发、volume 挂载、VS Code 插件配置 |
| `Dockerfile.devcontainer` | 开发专用镜像（Python 3.12 + Node.js 20 + bun） |

**端口转发：**

| 端口 | 用途 |
|------|------|
| `8765` | nanobot gateway 内部监听 |
| `18790` | nanobot gateway 对外端口 |
| `5173` | WebUI Vite dev server（自动打开浏览器） |
| `5174` | Vite HMR 热更新 |

**配置持久化：**  
`~/.nanobot/` 通过 named volume `nanobot-config` 持久化，重建容器后 API Key 和配置不会丢失。

## 方式二：本机直接安装

### 1. 安装后端依赖

```bash
cd /path/to/nanobot

# 从源码安装（获取最新特性）
pip install -e .

# 或使用 uv（更快）
uv pip install -e .
```

### 2. 安装前端依赖

```bash
cd webui

# 推荐使用 bun
bun install

# 或 npm
npm install
```

## 配置

### 1. 初始化（首次运行）

```bash
nanobot onboard
```

生成配置文件 `~/.nanobot/config.json`。

### 2. 编辑配置文件

```json
{
  "providers": {
    "openrouter": {
      "apiKey": "sk-or-v1-你的KEY"
    }
  },
  "agents": {
    "defaults": {
      "provider": "openrouter",
      "model": "anthropic/claude-opus-4-6"
    }
  },
  "channels": {
    "websocket": { "enabled": true }
  }
}
```

> `channels.websocket.enabled: true` 是启用 WebUI 的必要配置。

支持的 Provider 包括：OpenRouter、Anthropic、OpenAI、DeepSeek、Kimi、Qwen 等，详见 [configuration.md](./configuration.md)。

## 启动项目

### 终端 1：启动后端 Gateway

```bash
nanobot gateway
```

后端监听端口 **8765**（内部）/ **18790**（对外）。

### 终端 2：启动前端 WebUI

```bash
cd webui
bun run dev
# 或 npm run dev
```

Vite dev server 启动在 **http://localhost:5173**，自动代理 WebSocket 和 API 请求到 gateway。

## 端口汇总

| 服务 | 端口 | 说明 |
|------|------|------|
| nanobot gateway（内部）| `8765` | Vite proxy target |
| nanobot gateway（对外）| `18790` | 外部访问 / docker-compose 映射 |
| WebUI dev server | `5173` | 浏览器访问入口 |
| Vite HMR | `5174` | 热更新专用 |
| OpenAI 兼容 API（可选）| `8900` | `nanobot serve` 命令 |

## 其他启动模式

```bash
# CLI 对话模式（无需 WebUI）
nanobot agent

# 仅 CLI 单次对话
nanobot agent -m "你好"

# 查看状态
nanobot status

# 启动 OpenAI 兼容 API 服务
nanobot serve --host 0.0.0.0
```

## Docker Compose 部署（生产）

```bash
# 首次初始化
docker compose run --rm nanobot-cli onboard

# 编辑配置
vim ~/.nanobot/config.json

# 启动 gateway
docker compose up -d nanobot-gateway

# 查看日志
docker compose logs -f nanobot-gateway
```

详见 [deployment.md](./deployment.md)。
